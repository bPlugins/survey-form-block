# Survey Form Block & Form Builder

Effortlessly craft custom forms, surveys, and feedback forms in WordPress Gutenberg. Engage your audience, gather valuable insights, and build any form layout with versatile customization options.

---

## 🌟 Key Features

- **Versatile Form Builder Engine**: Create contact forms, surveys, feedback forms, or lead capture forms directly in Gutenberg.
- **Multi-Column Responsive Grid**: Adjust field column widths (`100%`, `66%`, `50%`, `33%`, `25%`) with mobile responsive auto-stacking.
- **Standard Input Fields**: Single Line Text, Multi-Line Paragraph Textarea, Email with format validation, Number (Min/Max/Step), Phone, and Website URL inputs.
- **Choice Controls**: Dropdown Select Menus, Checkbox Groups, Radio Buttons, and Switch/Toggle controls.
- **Interactive Survey & Feedback Widgets**:
  - **Star Rating**: 1-5 or 1-10 interactive star/icon rating widget.
  - **Opinion Scale**: 1-10 Likert scale rating bar.
  - **Net Promoter Score (NPS)**: 0-10 score selection with automatic Detractor, Passive, and Promoter category styling.
  - **Range Slider**: Smooth range slider input with live value indicator pill.
  - **Section Break Dividers**: Structural headers and divider lines for grouping form sections.
- **Enhanced Date Picker**: Date picker input with range boundaries.
- **Categorized Block Inspector**: Easy sidebar options to reorder, clone, delete, and configure labels, placeholders, and validation.
- **Design & Typography Customization**: Total control over typography, colors, padding, borders, background, and submit button styling.
